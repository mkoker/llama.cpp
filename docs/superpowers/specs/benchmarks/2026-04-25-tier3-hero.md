## Gate finding

The original hero gate shape used `-ngl 99` without `-ncmoe`:

`./build-hip/bin/llama-bench -m /mnt/nvme/models/qwen3-235b/Qwen3-235B-A22B-Q4_K_M-00001-of-00005.gguf -ngl 99 -fa 1 --expert-cache-size 24576 -p 0 -n 128 -r 1`

Result: model load failed before token generation.

Log: `logs/expert-cache/tier3-qwen3-235b-cache-on.out`

Failure signature:

`main: error: failed to load model '/mnt/nvme/models/qwen3-235b/Qwen3-235B-A22B-Q4_K_M-00001-of-00005.gguf'`

Root cause: full/high offload of the 132.39 GiB Q4_K_M MoE shard set does not fit the 32GB R9700. This is the same class of issue seen in Tier 2 with MiniMax full offload.

## Stable forced-offload hero configuration

Use constrained non-MoE layer offload plus CPU MoE expert offload:

- `-ngl 1`
- `-ncmoe 8`
- `-fa 1`
- `-p 0 -n 128 -r 1`
- cache off: `--expert-cache-size 0`
- cache on: `--expert-cache-size 24576`

This fits VM100 and exercises the scheduler CPU→GPU expert-copy path.
